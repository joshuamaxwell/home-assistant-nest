Privacy Policy

Effective November 20, 2026

"Home Assistant" is a private Google OAuth application used by one household to connect its own Home Assistant server to its own Google Nest thermostats. This policy describes the Google user data the app accesses and how that data is handled.

Data the app accesses

  • Google Nest device data through the Smart Device Management API: device and room names, temperature, humidity, thermostat mode, setpoints, and heating or cooling status.
  • Device event messages delivered through Google Cloud Pub/Sub.

The app does not access email, contacts, calendar, location history, or any other Google account data.

How the data is used

The data is used only to display and automate the household's own thermostats inside its Home Assistant installation.

Where the data is stored

The data is stored on the household's own Home Assistant server, which the household operates. It is not sent to the app developer's servers, because there are none.

Sharing

The data is not sold, shared, or transferred to any third party, and it is not used for advertising.

Retention and deletion

Thermostat history is kept on the household's Home Assistant server for as long as the household chooses. Removing the Google Nest integration from Home Assistant deletes the stored access tokens. Access can also be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent to the developer contact shown on the app's Google consent screen.
