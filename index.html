Home Assistant (Maxwell Home)

A private, single-household home automation connection.

What this app is

"Home Assistant" is the name of a private Google OAuth application that connects one household's own Home Assistant installation to that same household's Google Nest thermostats. It is not a public product or service, and it is not offered to anyone outside the household.

What it does

With the owner's permission, the app uses Google's Smart Device Management API to read thermostat temperature, humidity, mode and setpoints, and to change mode and setpoints. It uses Google Cloud Pub/Sub to receive updates when a thermostat's state changes. This lets the household's Home Assistant server display and automate its own thermostats.

Who can use it

Only the owner of the household's Google account. There is no sign-up, and no other users are supported.
